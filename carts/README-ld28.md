# ld28.b4

Ludum Dare 28 live map-editor port (see [b4-gd#6](https://github.com/tangentstorm/b4-gd/issues/6)).

Primary host is **b4/web** (`web/examples/ld28/` in [tangentstorm/b4](https://github.com/tangentstorm/b4)).
This cart is the same `__code__` for the Godot runner:

```bash
godot --path . -- cart=ld28
```

Room RAM `$800`, tools via register `B`, mouse paint + gravity in `:U`.
